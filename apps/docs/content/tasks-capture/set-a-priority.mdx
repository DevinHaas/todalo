Not every task on a busy day matters as much as the next. A priority lets you mark the few that do, so they stand out in a long list. Every task has one; most stay at the default.

## How priorities work

There are four priorities. Each one colours the task's circle and flag:

| Priority | Colour | Shown on the task |
| --- | --- | --- |
| **Priority 1 — highest** | Red | A red flag and "P1" |
| **Priority 2** | Orange | An orange flag and "P2" |
| **Priority 3** | Blue | A blue flag and "P3" |
| **Priority 4 — normal** | None | Nothing. This is the default for new tasks |

A priority only marks a task. It doesn't change the task's date or where it appears.

## Set a priority while adding a task

To set it as you add the task:

<Steps>
<Step>Open Quick Add and type the task.</Step>
<Step>Click the **Priority** chip under the name.</Step>
<Step>Choose a priority, then press Enter to add the task.</Step>
</Steps>

## Change a task's priority

To change it later:

<Steps>
<Step>Open the task.</Step>
<Step>Click the flag next to **Priority** on the right.</Step>
<Step>Choose a priority.</Step>
<Step>Click **Save**.</Step>
</Steps>

You can also right-click the task in a list, point to **Priority** and choose one. That change is saved straight away.

<Tip>On a task in a list, press <Shortcut keys="1" />, <Shortcut keys="2" />, <Shortcut keys="3" /> or <Shortcut keys="4" /> to set its priority, or <Shortcut keys="Y" /> to choose from a list.</Tip>

## Set a priority on several tasks

To change many tasks at once, click **Select** at the top of the list, tick the tasks, then click **Priority** in the toolbar. [Add or manage multiple tasks](/tasks-capture/add-or-manage-multiple-tasks) walks through it.

## Sort and filter by priority

In a project, click **Display** at the top of the project. Under **Sort**, set **Grouping** or **Sorting** to **Priority** to bring your highest priorities to the top. Under **Filter**, **Priority** shows only the tasks with one priority.

A filter can collect high-priority tasks from every project. Type `p1` in a filter query for priority 1 tasks, or `no priority` for priority 4. [Introduction to filters](/organise-views/introduction-to-filters) explains how to build one.
