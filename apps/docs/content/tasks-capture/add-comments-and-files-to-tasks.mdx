A task's name says what to do, but not always what you found out along the way: the quote a plumber gave you, the link to the form, where you got to. Comments keep those notes on the task itself. Files go into a project, where each one becomes a task you can open and download from.

## Add a comment

To add a comment:

<Steps>
<Step>Open the task.</Step>
<Step>Under **Comments**, click the **Comment** field.</Step>
<Step>Type your note. Press Shift+Enter to start a new line.</Step>
<Step>Press Enter. The comment is saved and shows with the date and time you added it.</Step>
</Steps>

Web addresses in a comment become links you can click. So do links written as `[text](https://…)`, which is how comments imported from Todoist arrive.

In a list, a task with comments shows a speech bubble with the number of comments.

<Note>Comments are notes for yourself. Todalo has no shared projects, so nobody else sees them.</Note>

## Delete a comment

Point at the comment and click the cross (**Delete comment**) at its right. The comment is deleted straight away.

## Add files as tasks

Todalo attaches files by turning each one into a task in a project. The file is attached to the new task, which is named after it. To add files:

<Steps>
<Step>Open the project.</Step>
<Step>Below its tasks, click **Add files**.</Step>
<Step>Choose up to five files. The project shows "Saving files…", then how many file tasks were created.</Step>
</Steps>

You can also drag files from your desktop onto the project, or copy them and paste with <Shortcut keys="Mod+V" /> while the project is open.

<Note>You can add up to 5 files at a time, each up to 5 MB and 10 MB together. Files can only be added to a project, not to the Inbox or to a task that already exists.</Note>

## Open an attached file

A file task lists its file on its task page:

<Steps>
<Step>Open the task, click **More actions** at the top right, then **Open task page**.</Step>
<Step>Under **Attachments**, click the file's name.</Step>
</Steps>

<Platform on="web">
Your browser downloads the file to its usual downloads folder.
</Platform>

<Platform on="mac">
Todalo saves the file and shows where it went, for example "Saved quote.pdf to Downloads."
</Platform>

If a file upload is interrupted, Todalo says so and offers **Retry upload**. Check the project first: some files may already have been added.
